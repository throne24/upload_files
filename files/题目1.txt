1.设置主机名
hostnamectl set-hostname dns.wyulinuxos.com


2.修改主配置文件 
#vi /etc/named.conf
找到并修改以下两行（将 localhost 改为 any）：
listen-on port 53 { any; };
allow-query     { any; };


3.修改区域配置文件
#vi /etc/named.rfc1912.zones
在文件末尾添加正向和反向区域：
zone "wyulinuxos.com" IN {
        type master;
        file "data/wyulinuxos.com.zone";
        allow-update { none; };
};

zone "90.24.172.in-addr.arpa" IN {
        type master;
        file "data/172.24.90.arpa";
        allow-update { none; };
};


4.创建正向区域文件
cp /var/named/named.localhost /var/named/data/wyulinuxos.com.zone
vi /var/named/data/wyulinuxos.com.zone
写入以下内容：
$TTL 1D
@   IN SOA  dns.wyulinuxos.com. admin.wyulinuxos.com. (
                    1   ; serial
                    1D  ; refresh
                    1H  ; retry
                    1W  ; expire
                    3H)    ; minimum
    	IN NS   dns.wyulinuxos.com.
dns 	IN A    172.24.90.1
www2 IN A   172.24.90.1
ftp3 IN A   172.24.90.1
mail4 IN A  172.24.90.1
course IN A 172.24.90.201
@   IN MX 10 mail4.wyulinuxos.com.


5.创建反向区域文件 /var/named/data/172.24.90.arpa
cp /var/named/named.localhost /var/named/data/172.24.90.arpa
vi /var/named/data/172.24.90.arpa
写入以下内容：
$TTL 1D
@   IN SOA  dns.wyulinuxos.com. admin.wyulinuxos.com. (
                    0   ; serial
                    1D  ; refresh
                    1H  ; retry
                    1W  ; expire
                    3H )    ; minimum
    IN NS   dns.wyulinuxos.com.
1   IN PTR  dns.wyulinuxos.com.
1   IN PTR  www2.wyulinuxos.com.
1   IN PTR  ftp3.wyulinuxos.com.
1   IN PTR  mail4.wyulinuxos.com.
201 IN PTR  course.wyulinuxos.com.


6.修改权限并重启服务
chown root:named /var/named/data/wyulinuxos.com.zone /var/named/data/172.24.90.arpa
named-checkconf
named-checkzone wyulinuxos.com /var/named/data/wyulinuxos.com.zone
named-checkzone 90.24.172.in-addr.arpa /var/named/data/172.24.90.arpa
systemctl enable named
systemctl restart named
